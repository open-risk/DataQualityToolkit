Roadmap
=========================

DataQualityToolkit aims to be a versatile tool to analyse data quality issues using Python.

This roadmap lays out upcoming steps in this journey.

0.2.X
--------------------------

The 0.2.X family of releases will focus on rounding out a number of functionalities already introduced

- Excel sheets
- Wikitables
- Automated reports
- Automated visualizations

Feature requests, bug reports and any other issues are welcome to log at the `Github Repository <https://github.com/open-risk/DataQualityToolkit>`_
